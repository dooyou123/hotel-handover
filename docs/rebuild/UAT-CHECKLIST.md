# UAT 체크리스트 (2~3명 · 스테이징)

> **목적:** Vercel 스테이징 URL에서 기능 parity·Realtime·권한 검증  
> **기간:** W6 (컷오버 W7 전)  
> **테스터:** 프런트 직원 2명 + 매니저 1명 권장

---

## 사전 준비

- [ ] 스테이징 URL 공유 (Vercel Preview 또는 Production)
- [ ] 테스트 계정 3개 (staff 2 + manager 1) Supabase에 등록
- [ ] manager 계정 `profiles.role = 'manager'` 확인
- [ ] `seed.sql` 또는 마이그레이션 리허설 데이터 존재
- [ ] PC 2대 이상 준비 (Realtime 테스트)

**환경 변수 (Vercel):**

- [ ] `NEXT_PUBLIC_SUPABASE_URL`
- [ ] `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- [ ] `NEXT_PUBLIC_DEFAULT_HOTEL_ID=00000000-0000-4000-8000-000000000001`

**Supabase Auth → URL Configuration:**

- [ ] Site URL = 스테이징 URL
- [ ] Redirect URLs에 `https://*.vercel.app/**` 포함
