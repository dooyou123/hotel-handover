# 프런트 인수인계 보드 — 사용 매뉴얼

> Next.js + Supabase 버전 · 현장 직원·매니저용

---

## 1. 시작하기

### 로그인

1. 브라우저에서 배포 URL 접속 (예: `https://handover.example.com` 또는 Vercel 스테이징 URL)
2. **직원 이메일** · **비밀번호** 입력 → 로그인
3. 계정은 Supabase Dashboard에서만 추가됩니다 (자가 가입 없음)

### 지금 근무 (필수)

로그인 후 상단 **지금 근무**에서:

| 항목 | 설명 |
|------|------|
| **교대** | 주간 / 오후 / 야간 |
| **담당자** | 설정 탭에 등록된 직원 이름 |

선택하지 않으면 카드 추가·긴급 확인·댓글·체크리스트·어메니티 기록 시 안내 팝업이 뜹니다.

**오늘 근무** 블록에서 스케줄에 등록된 이름을 클릭하면 교대·담당자가 자동 입력됩니다.

## 2. 인수인계 탭

### 칸반 보드

| 칸 | 용도 |
|----|------|
| **긴급** | 다음 교대가 반드시 확인·처리 |
| **진행중** | 당일 처리 또는 넘김 |
| **완료** | 처리 완료 (교대 후 비울 수 있음) |

- 카드를 **드래그**하여 칸 이동
- **객실** 뷰: 객실번호별 묶음 보기
- **검색** · **빠른 필터** · **카테고리**로 목록 좁히기

### 카드 작성·수정

- **+ 인수인계**: 새 카드 (제목 필수)
- **템플릿**: 새 카드 모달 상단 버튼 (설정에서 관리)
- **완료** 칸 저장 시 **처리 결과** 필수
- **댓글** · **사진 첨부** (카드당 최대 2장, 2MB)

### 긴급 확인

긴급 칸 카드 하단 **✓ 긴급 확인** — 교대·담당자 선택 후 클릭. 확인 이력이 카드에 표시됩니다.

### 공지 · 변경

- **업무 공지** / **업무 변경** 패널에서 추가
- 📌 핀 고정, 유효기간(변경) 설정 가능
- 매니저만 삭제 가능

### 교대 · 요약

| 버튼 | 설명 |
|------|------|
| **▶ 교대 시작** | 인수 요약 확인 후 기록 |
| **■ 교대 종료** | 마감 확인·메모·체크리스트 미완료 표시 |
| **일일 요약** | txt / 인쇄(PDF) / png 내보내기 |
| **변경 기록** | 카드·공지 추가/수정/삭제/이동 로그 |

## 8. Realtime (동시 사용)

여러 PC에서 동시에 사용할 때 카드·공지 변경은 **자동 반영**됩니다.  
반영이 늦으면 새로고침(F5) 후 다시 확인하세요.

---

## 9. 매니저 계정 설정 (관리자)

Supabase Dashboard → SQL Editor:

```sql
insert into public.profiles (id, hotel_id, display_name, role)
select
  u.id,
  '00000000-0000-4000-8000-000000000001',
  split_part(u.email, '@', 1),
  'manager'
from auth.users u
where u.email = 'manager@example.com'
on conflict (id) do update
set role = 'manager', updated_at = now();
```

적용 후 **로그아웃 → 재로그인**.
