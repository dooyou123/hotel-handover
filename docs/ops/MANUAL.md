## 1. 시작하기

### 로그인

1. 브라우저에서 배포 URL 접속
2. **직원 이메일** · **비밀번호** 입력 → 로그인
3. 계정은 Supabase Dashboard에서만 추가됩니다 (자가 가입 없음)

### 지금 근무 (필수)

로그인 후 상단 **지금 근무**에서:

| 항목 | 설명 |
|------|------|
| **교대** | 주간 / 오후 / 야간 |
| **조** | A / B / C (체크리스트·인수인계 그룹) |
| **담당자** | 설정 탭에 등록된 직원 이름 |

선택하지 않으면 카드 추가·긴급 확인·댓글·체크리스트·어메니티 기록 시 안내 팝업이 뜹니다.

### 사이드바 메뉴

| 그룹 | 메뉴 |
|------|------|
| **업무** | 인수인계, 팀 소식·일정, 스케줄, 휴무 신청 |
| **운영** | 연락처, 체크리스트, 하우스키핑, 어메니티, 리뷰, 픽업·택시, 시설 현황, 객실료 컨펌 |
| **분석** | 통계 |
| **시스템** | 설정 |

헤더 **🔍 객실** 버튼으로 객실 번호를 통합 검색할 수 있습니다(인수인계·리뷰·하우스키핑 등).

관리자는 설정 → **메뉴** 탭에서 직원에게 보이지 않을 메뉴를 숨길 수 있습니다.

## 2. 인수인계 탭

### 화면 구성

- **왼쪽 (인수인계장)**: 목록·객실 뷰, 빠른 필터, 검색, 보관함, 새 인수인계
- **오른쪽 패널**: 업무 현황, 교대·기록, 고정 공지, 오늘 할일·일정
- **상단 바**: 오늘 택시 예약(미완료), 어메니티 재고 부족 알림
- **상단 전광판**: 미확인 긴급·고정 공지 스크롤

### 목록 · 상태

| 상태 | 설명 |
|------|------|
| **진행중** | 처리 중 업무 (긴급 우선순위가 상단) |
| **완료** | 처리 완료 — 교대 후 보관 가능 |
| **보관함** | 완료 건 장기 보관 |

- **목록** / **객실** 뷰 전환
- **검색**: 보관함 왼쪽 — 객실·제목·댓글·담당자, **기간** 버튼으로 날짜 범위
- **빠른 필터**: 전체, 내 담당, 미확인 긴급, 룸클린 등

### 카드 작성·수정 (오른쪽 드로어)

- **+ 새 인수인계**: 새 카드 (제목 필수)
- **템플릿**: 드로어 상단 버튼 (설정에서 관리)
- **완료** 저장 시 **처리 결과** 필수
- **댓글** · **사진 첨부** (카드당 최대 2장, 2MB)
- **할일 연동**: 카드에서 할일 생성·연결

### 긴급 확인

긴급 우선순위 카드 **✓ 긴급 확인** — 교대·담당자 선택 후 클릭. 확인 이력이 카드에 표시됩니다.

### 교대 · 요약

| 버튼 | 설명 |
|------|------|
| **▶ 교대 시작** | 인수 요약 확인 후 기록 |
| **■ 교대 종료** | 마감 확인·메모·체크리스트 미완료 표시 |
| **교대 브리프** | 별도 창 인쇄용 요약 |
| **일일 요약** | txt / 인쇄(PDF) / png보내기 |
| **변경 기록** | 카드·공지 로그 — 검색·필터·Realtime 갱신 |

## 4. 업무 일정 · 스케줄

### 업무 일정 (`/todos`)

- **할일** + **호텔 일정**(교육·VIP·점검)을 한 목록에서 관리
- 할일: 우선순위·마감·반복·인수인계 연동
- 일정: 날짜·시간·카테고리 (목록 「일정」 뱃지)

### 스케줄 (`/schedules`)

- 월별 스케줄 이미지를 버전별로 등록하고 확인
- 변경 메모와 직원 호명으로 확인 요청
- 이전 버전 비교·다운로드·인쇄 지원

## 7. 하우스키핑 · 어메니티 · 리뷰

### 하우스키핑

- 4~13층 02·10·16호 EB·특이 객실 일별 보고, 인쇄

### 어메니티

- 품목별 재고·입출고, Realtime 동기화
- 품목 선택 후 **최소 재고(알림)** 설정 — 재고가 이하이면 상단 알림

### 리뷰

- 긍정/부정 리뷰 등록, **객실 조치 완료**·취소, **인수인계 후속** 카드 생성

### 픽업·택시

- 예약 등록(날짜·시간·객실·목적지), 상태 변경
- 당일 예약 30분 전 상단 알림

### 시설 현황

- 루틴 A/B/C 템플릿, 시설 이슈 기록·해결 이력

### 객실료 컨펌

RAW 데이터(CSV·Excel)와 PMS보내기를 업로드해 객실료를 대조합니다.

1. **RAW 파일** · **PMS 파일** 각각 업로드
2. 열 매핑 확인(예약번호·객실·날짜·금액 — 자동 추측 후 수정 가능)
3. 결과: 일치 / 불일치 / RAW만 / PMS만, 차이 금액 확인

매칭 우선순위: 예약번호 → 없으면 객실+날짜

## 11. 매니저 계정 설정 (관리자)

Supabase Dashboard → SQL Editor:

```sql
insert into public.profiles (id, hotel_id, display_name, role)
select
  u.id,
  '00000000-0000-4000-8000-000000000001',
  split_part(u.email, '@', 1),
  'manager'
from auth.users u
where u.email = 'manager@example.com'
on conflict (id) do update
set role = 'manager', updated_at = now();
```

적용 후 **로그아웃 → 재로그인**.
