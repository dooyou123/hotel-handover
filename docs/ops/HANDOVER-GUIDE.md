# 인수인계 운영 기준 (직원 공유용)

> **목적:** 예전 엑셀 인수인계처럼 「상시 안내 + 당일 업무 + 공지」가 한곳에 섞이지 않게 하고, **교대 인수 시간을 줄이기** 위한 기준입니다.  
> **적용:** 프런트 전 조 (A/B/C) · 주간/오후/야간 공통

---

## 1. 한 줄 요약

| 어디에? | 무엇을? |
|---------|---------|
| **게시판** | 알아두면 되는 안내·정책 (매 교대 안 읽음) |
| **인수인계 카드** | 지금 처리하거나 다음 조에 넘겨야 하는 **업무** |
| **업무 일정** | 할일 + 호텔 일정(교육·VIP·점검 등) — **한 메뉴** |
| **근무표** | 조별 근무 CSV·휴무 신청만 |
| **택시 예약** | 픽업 예약 (상단 바 + 택시 메뉴) |

**원칙:** 인수인계장에는 **움직이는 일**만 둡니다. 긴 설명·매뉴얼은 게시판에 둡니다.

---

## 2. 어디에 올릴까? (판단 기준)

### 2-1. 게시판 (업무 공지 / 업무 변경)

**올리는 것**

- 기간이 긴 안내 (이벤트, 패키지, 방역 정책 등)
- 「항상 이렇게 하세요」류 매뉴얼
- 전 조가 알아두면 좋지만 **당장 손댈 건 없는** 내용
- 엑셀 **「상시 인계」**에 해당하던 글

**설정**

- 📌 **고정** — 자주 찾는 안내
- **유효기간** — 끝나는 날짜가 있으면 반드시 설정 (엑셀 End 열과 동일)

**올리지 않는 것**

- 특정 객실 O.O, 당일 시설 작업, 손님 민원 진행 건 → **인수인계 카드**

---

### 2-2. 인수인계 카드

**올리는 것**

- 처리 중이거나 다음 교대에 **넘겨야 하는 업무**
- 객실 이슈, 시설 고장, 컴플레인, 업체·HK 대기 건
- 엑셀 **「데일리 인계」**·진행 중 이슈

**한 카드 = 한 건**

- 제목은 짧게 (예: `1207 냉난방 불량`, `0608 욕조 누수 O.O`)
- 긴 경과는 **댓글**로 추가 (본문을 계속 고치지 않음)
- 사진이 있으면 첨부 (최대 2장)

**올리지 않는 것**

- 3개월짜리 이벤트 안내 전문 → **게시판**
- 「6/17 14:00 교육」만 알리면 되는 것 → **일정** (+ 필요 시 당일 카드)
- 「6/15 트랩 확인」처럼 날짜만 있는 단순 리마인더 → **할일**

---

### 2-3. 업무 일정 (할일 + 호텔 일정)

**메뉴 이름:** 「업무 일정」 — 할일과 호텔 일정을 **한곳**에서 봅니다.

| 종류 | 올리는 것 | 예시 |
|------|-----------|------|
| **할일** | 마감·담당이 있는 처리 건, 반복 점검 | `6/15 트랩 확인`, HK 공유 요청 |
| **일정** | 날짜·시간이 있는 행사·교육·점검 | `6/17 CPR 14:00`, `6/18 소테츠의 밤` |

- 인수인계와 **할일** 연동 가능
- 「근무표」에는 **넣지 않음** (근무표 = A/B/C 누가 근무하는지만)

---

### 2-4. 근무표

**올리는 것**

- 조별 근무 CSV, 개별 근무 추가·수정
- 휴무 신청

**올리지 않는 것**

- CPR 교육, VIP, 점검 → **업무 일정**의 「일정」

---

### 2-5. 택시 예약

- 픽업 예약은 **택시 예약** 메뉴에만 등록
- 오늘 미완료 건은 **상단 노란 바**에 표시 (완료 처리할 때까지)
- 인수인계 카드에 택시 내용을 중복 적지 않음

---

## 3. 우선순위 (상태)

인수인계 카드 작성 시 **우선순위**를 이렇게 고릅니다.

| 우선순위 | 언제 쓰나 | 예시 |
|----------|-----------|------|
| 🔴 **긴급** | 지금·즉시 확인·조치. 교대 넘길 때 **✓ 긴급 확인** 필요 | O.O 객실, 응급 민원, 결제·안전 이슈 |
| 🟡 **오늘** | 오늘 안에 처리하면 되는 일 | 당일 방역·청소, 오늘 회신 약속 |
| ⚪ **참고 요망** | 당장 손대지 않아도 됨. 다음 조가 **알아두면 되는** 전달 | 짧은 주의사항, 참고 메모 |

**칸 (진행 상태)**

| 칸 | 언제 쓰나 |
|----|-----------|
| **진행중** | 지금 처리 중 |
| **보류** | 아직 안 끝났지만 HK·손님·업체 회신 등 **대기** |
| **완료** | 처리 끝 — **처리 결과** 필수 입력 후 저장 |

## 4. 교대별 해야 할 일

### 교대 시작 (약 3~5분)

1. 상단 **지금 근무** (교대 · 조 · 이름) 설정
2. **인계** 탭 → 교대 시작 확인
3. 아래 순서만 확인 (고정 공지 전체를 읽지 않음)
   - 미확인 **긴급** → ✓ 긴급 확인
   - **긴급**·**진행중**·**보류** 카드
   - 오른쪽 **오늘 업무 일정** · 택시
4. 상단 **택시 바**·**어메니티** 알림 있으면 확인

### 근무 중

| 상황 | 행동 |
|------|------|
| 새 이슈 발생 | **인수인계 카드** 추가 |
| 진행 상황만 바뀜 | 카드 **댓글** 추가 |
| 정책·안내가 새로 생김 | **게시판** (필요 시 고정) |
| 날짜 잡힌 후속 일 | **업무 일정** (할일 또는 일정) |
| 끝남 | **완료** + 처리 결과 |

### 교대 종료

1. 본인이 처리한 카드 **완료** 처리
2. 못 끝낸 건 **보류** 또는 **진행중** 유지 + 댓글로 상태 남기기
3. **교대 종료** 기록 (필요 시 메모)

## 5. 엑셀에서 옮길 때

| 예전 엑셀 | 지금 앱 |
|-----------|---------|
| 상시 인계 | 게시판 + 📌 고정 + 유효기간 |
| 데일리 인계 | 인수인계 카드 |
| 추후 인계 | 업무 일정(할일) 또는 보류 카드 |
| 주제 (FD, HK 등) | 카테고리 · 담당 조 |
| End 날짜 | 게시판 유효기간 |
| 완료 체크 | 카드 완료 → (자동) 보관 |
| 연락처 시트 | 연락처 메뉴 |
| 근무표 시트 | 근무표 메뉴 |
| 데일리 중 교육·행사 | 업무 일정 → 일정 |

---

## 6. 자주 하는 실수 (하지 말 것)

1. ❌ 긴 공지·이벤트 안내를 인수인계 카드에 그대로 붙여 넣기  
2. ❌ 한 카드에 객실 3건·시설 2건을 한꺼번에 적기  
3. ❌ 진행만 바뀌었는데 본문 전체 수정 (→ **댓글** 사용)  
4. ❌ 택시·할일·일정 내용을 인수인계에 또 적기 (중복)  
5. ❌ 교대마다 고정 공지 전부 읽기 (→ **인계 브리핑·오늘 패널**만)
